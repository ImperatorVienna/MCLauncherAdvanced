# MC Launcher Advanced 1.0.2

本次更新统一启动器图标，完善官方内容与声明文档的排版，修正字体和英文文案，并补充维护者与素材来源信息。

## 图标与桌面集成

- 启用新的 MCLA 草方块图标，采用灰色立体字样和等轴测排布。
- 统一启动器窗口、Linux 应用入口、Windows 可执行文件与桌面快捷方式的图标，并更新浏览器预览图标。
- 修正 Linux GTK 应用身份与桌面入口的匹配，使 Wayland 能正确关联启动器图标。

## 界面与文案

- 手柄图样中的字母按键统一使用内置字体，避免随电脑的系统字体变化；其他界面中的同类字体引用也已整理。
- 官方游戏更新说明采用启动器统一的标题、段落、列表、表格和间距标准；来源说明右侧提供标准字号的官网按钮。
- 官方新闻与游戏更新说明统一保留英文原文；按钮、提示与来源说明仍随界面语言切换。
- 重新整理第三方声明的层级与排版，将素材来源说明与第三方组件许可证分区展示。第三方声明和许可证原文均使用英文。
- 核对中英文界面文案及后端错误提示，补齐信息对应关系，并增加翻译键、占位符和错误提示的回归检查。

## 项目信息

- 在“设置 → 关于”增加维护者主页入口，并补充个人维护者、联系方式及独立项目说明。
- 补充界面设计、图标、纹理、皮肤、背景、字体和第三方组件的来源与权利声明，区分项目原创代码的 GPL-3.0-only 授权与第三方素材权利。

## 认证与隐私

- 分离 Microsoft 认证服务与 Tauri IPC 命令，系统浏览器和凭据权限仍通过平台适配器处理。
- 增加权益响应结构校验和刷新失败、账户限制错误、取消登录的模拟测试；不会将空权益列表直接判为无资格。
- 增加双语隐私说明，记录账户数据保存、外部连接、本地删除方式和日志处理。

## 修复

- 修复滚动资源列表时，上下导航可能误跳到固定选项卡的问题；优先访问列表中相邻的可操作行，并保持翻页后的焦点规则。

- 修复 Linux 桌面版复制日志或错误信息时可能被内置浏览器权限阻止的问题，改用系统原生剪贴板；复制失败时显示对应语言的提示。

## 已知限制

- Minecraft API 访问尚未获批；Microsoft 登录目前仍无法完成所需的 Minecraft 认证流程，本次更新不改变这一状态。
- 皮肤库仅支持本地导入与预览，尚未接入向账户上传或应用皮肤。
- 官方新闻与游戏更新说明依赖网络和上游数据，部分游戏版本可能没有对应文章。
- Windows 构建仍需实机验收，尤其是窗口与快捷方式图标、WebView2、手柄和自动更新。交叉编译通过不等于完成实机验证。
- 部分美术素材的再分发许可尚未确认，详见项目素材声明；来源记录不等于授权。

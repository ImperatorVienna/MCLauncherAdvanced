# MC Launcher Advanced 1.0.2

This update unifies launcher icons, improves the layout of official content and notices, corrects fonts and English wording, and adds maintainer and asset provenance information.

## Icons and desktop integration

- Introduced the MCLA grass-block icon with gray three-dimensional lettering and an isometric layout.
- Unified icons for the launcher window, Linux application entries, Windows executable and desktop shortcut, and updated the browser preview icon.
- Corrected the association between the Linux GTK application identity and desktop entry so Wayland can resolve the launcher icon correctly.

## Interface and wording

- Lettered controller buttons now use the bundled font consistently instead of varying with the computer's system fonts. Similar font references elsewhere in the interface have also been consolidated.
- Official game release notes now follow the launcher's heading, paragraph, list, table and spacing standards. A website button with the standard button font size appears beside the source label.
- Official news and game release notes retain their English source content. Buttons, messages and source labels continue to follow the interface language.
- Reorganized third-party notices with clear sections for asset provenance and component licenses. Third-party notices and original license texts are displayed in English.
- Reviewed Chinese and English interface text and backend error messages for equivalent information, and added regression checks for translation keys, placeholders and error messages.

## Project information

- Added a maintainer homepage button to Settings → About, along with individual maintainer details, contact information and an independent-project statement.
- Added provenance and rights notices for the interface design, icon, textures, skins, backgrounds, fonts and third-party components, distinguishing the GPL-3.0-only license for original project code from third-party asset rights.

## Authentication and privacy

- Separated the Microsoft authentication service from Tauri IPC commands. System browser access and credential permissions still use platform adapters.
- Added entitlement response structure validation and simulated tests for refresh failures, restricted-account errors and sign-in cancellation. An empty entitlement list alone is not treated as proof of ineligibility.
- Added bilingual privacy documentation covering account storage, external connections, local deletion and log handling.

## Fixes

- Fixed up/down navigation jumping to fixed tabs while scrolling resource lists. Adjacent actionable content rows take priority, and pagination focus behavior is preserved.

- Fixed Linux desktop copying of logs or error messages being blocked by embedded browser permissions by using the native system clipboard. Copy failures now display a message in the selected interface language.

## Known limitations

- Minecraft API access has not been approved; Microsoft sign-in still cannot complete the required Minecraft authentication flow. This update does not change that status.
- The skin library supports only local import and preview. Uploading or applying skins to an account is not implemented.
- Official news and game release notes depend on network access and upstream data. Some game versions may not have a corresponding article.
- Windows builds still require real-device acceptance testing, particularly window and shortcut icons, WebView2, controllers and automatic updates. Successful cross-compilation does not constitute runtime validation.
- Redistribution permission for some artwork remains unconfirmed; see the project's asset notices. Provenance does not constitute permission.

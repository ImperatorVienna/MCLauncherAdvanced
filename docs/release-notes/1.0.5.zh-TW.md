# MC Launcher Advanced 1.0.5

- 新增繁體中文介面、錯誤提示、隱私說明和 README，支援儲存語言選擇。
- 統一中文“資源包／資源包”和“光影包”文案。
- Linux 應用 ID 與可見入口統一為 `minecraft.launcher.advanced`，啟動時清理兩個舊入口並遷移指向它們的桌面符號連結；Windows 應用 ID 和入口行為保持不變。
- 修復皮膚編輯／刪除取消後的焦點恢復，以及離開頁面後非同步儲存搶佔焦點的問題。
- 整理應用註冊介面，移除重複寫入、無用引數和過時文案。
- 「有什麼新內容？」僅載入目前介面語言的啟動器更新公告；切換語言後重新載入對應公告，不回退至其他語言。

# MC Launcher Advanced 1.0.5

- 新增繁体中文界面、错误提示、隐私说明和 README，支持保存语言选择。
- 统一中文“资源包／資源包”和“光影包”文案。
- Linux 应用 ID 与可见入口统一为 `minecraft.launcher.advanced`，启动时清理两个旧入口并迁移指向它们的桌面符号链接；Windows 应用 ID 和入口行为保持不变。
- 修复皮肤编辑／删除取消后的焦点恢复，以及离开页面后异步保存抢占焦点的问题。
- 整理应用注册接口，移除重复写入、无用参数和过时文案。
- “有什么新内容？”仅加载当前界面语言的启动器更新公告；切换语言后重新加载对应公告，不回退到其他语言。

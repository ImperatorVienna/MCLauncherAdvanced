# MC Launcher Advanced 1.0.3

## New features

- Added a Copy authorization code button to the sign-in page.
- Display the signed-in Minecraft account's skin in the sidebar avatar and skin page.
- Upload and apply bundled or locally imported skins, and switch between Classic and Slim arms. Click Use skin to apply changes to the account.
- Added English and Simplified Chinese text for new buttons, status messages and errors.

## Fixes

- Fixed Microsoft account sign-in for Minecraft.
- Fixed reading and changing the signed-in account's Minecraft skin.

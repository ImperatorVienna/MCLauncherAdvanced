# MC Launcher Advanced 1.0.1

本次更新补齐官方新闻、游戏更新说明和项目介绍，新增手柄操作示意图，并改进设置页面、新闻卡片和文档弹窗的显示与交互。

## 新增

- 首页五张新闻卡片接入 Java 版官方新闻，点击可阅读对应的 Minecraft 官方文章。
- 游戏“更新说明”根据当前配置的 Minecraft 版本加载对应的官方文章。切换配置后同步切换内容，避免旧请求的结果覆盖新配置。
- 设置中新增“关于”选项卡，集中展示启动器版本、检查更新、项目主页、开源许可证及第三方声明。
- 项目自有代码采用 GNU GPL 3.0 许可证（GPL-3.0-only）；第三方组件与素材仍遵循各自许可。

## 界面与交互

- 侧栏底部显示版本号，替换原有的状态小字。
- 手柄设备列表改为下拉菜单，选择设备后展示对应的操作示意图。未检测到设备时不显示图样。
- 收到有效手柄输入后静默切换当前设备的图示，不跳转页面、不移动焦点。
- 补齐 Xbox、PlayStation、Nintendo Switch Pro 与通用手柄的按键图样，统一单色功能键配色、尺寸和对齐。
- 首页新闻卡片文字增加内边距，调整长标题换行和窄窗口显示。
- “开源许可证”和“第三方声明”改用与启动器日志一致的弹窗形式，修正第三方声明不能立即显示的问题。
- 文档可独立滚动；关闭弹窗后，焦点返回打开它的按钮。支持键盘焦点循环及返回操作。
- 启动器更新公告中的更新入口改为跳转“关于”，并将焦点移到更新按钮。
- 整理说明文字、控件间距及长文本显示；补齐新增界面的简体中文和英文文案。官方文章继续保留原文。

## 已知限制

- Minecraft API 访问尚未获得批准，首次申请已被拒绝；当前 Microsoft 登录无法完成所需的 Minecraft 认证流程。本次更新不解决这一限制，也不代表审核已通过。
- 皮肤库仍仅支持本地导入与预览，尚未接入向账户上传或应用皮肤。
- 官方新闻与游戏更新说明依赖网络及上游数据；部分游戏版本可能没有对应文章。加载失败时会显示提示，支持重试。

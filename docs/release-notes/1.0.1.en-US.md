# MC Launcher Advanced 1.0.1

This update adds official news, game release notes, project information and controller operation diagrams, and improves the presentation and interaction of Settings, news cards and document dialogs.

## New features

- The five home-page news cards now show official Java Edition news. Select a card to read the corresponding official Minecraft article.
- Game release notes load the official article for the selected instance’s Minecraft version. Switching instances updates the content, and responses from earlier requests cannot overwrite the newly selected instance’s notes.
- A new About tab in Settings brings together the launcher version, update checks, project homepage, open-source license and third-party notices.
- Project-owned code is licensed under GNU GPL 3.0 (`GPL-3.0-only`). Third-party components and assets retain their respective licenses.

## Interface and interaction

- The bottom of the sidebar now displays the version number instead of the previous status text.
- The controller device list is now a dropdown. Selecting a device displays its operation diagram. No diagram is shown when no device is detected.
- Valid controller input silently switches the diagram to the active device without changing the page or moving focus.
- Added button diagrams for Xbox, PlayStation, Nintendo Switch Pro and generic controllers, with consistent colors, sizes and alignment for monochrome function buttons.
- Added padding around news-card text and improved long-title wrapping and narrow-window layouts.
- The open-source license and third-party notices now use dialogs consistent with the launcher log dialog. Fixed third-party notices not appearing immediately when opened.
- Documents scroll independently. Closing a dialog returns focus to the button that opened it. Keyboard focus cycling and the Back action are supported.
- The update shortcut in launcher release announcements now opens About and focuses the update button.
- Refined explanatory text, control spacing and long-text layout. Added Simplified Chinese and English wording for the new interface elements. Official articles retain their original language.

## Known limitations

- Minecraft API access has not been approved; the initial application was declined. Microsoft sign-in currently cannot complete the required Minecraft authentication flow. This update does not resolve that limitation or indicate approval.
- The skin library still supports only local import and preview. Uploading or applying skins to an account is not implemented.
- Official news and game release notes depend on network access and upstream data. Some game versions may not have a corresponding article. Failed requests display a message and can be retried.

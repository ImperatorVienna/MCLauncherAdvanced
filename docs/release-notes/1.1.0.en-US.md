# MC Launcher Advanced 1.1.0

- Switch Microsoft sign-in to the official launcher's Xbox Sisu flow, completed in a Microsoft window opened by the launcher without entering a device code in the browser.
- Close the window automatically after sign-in; closing it cancels the attempt. The sign-in window does not keep cookies, making account switching easier.
- Store the launcher's Xbox device key with the refresh token in the local `accounts.json`, never in the interface. Existing accounts move to the new flow on their next token refresh; if asked to sign in again, sign in once.
- Fix bundled skins failing to apply with "Load failed" in packaged builds.
- Update the privacy notices and account documentation in all three languages.

# MC Launcher Advanced 1.1.0

## Microsoft sign-in

- Microsoft sign-in now uses the official launcher's Xbox Sisu flow: choose Sign in and complete it in the Microsoft window the launcher opens. Entering a device code in the browser is no longer required.
- The window closes automatically after sign-in; closing it cancels the attempt. The sign-in window does not keep cookies, which makes switching between accounts easier.
- The launcher generates an Xbox device key and stores it with the refresh token in the local `accounts.json`; it is never sent to the interface.
- Existing accounts switch to the new flow on their next token refresh. If you are asked to sign in again, signing in once is enough.

## Fixes

- Fix bundled skins (Steve, Alex and others) failing to apply with "Load failed" in packaged builds.

## Other

- Update the privacy notices and account documentation in all three languages to describe the new sign-in method and locally stored data.

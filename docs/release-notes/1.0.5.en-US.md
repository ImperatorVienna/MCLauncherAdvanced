# MC Launcher Advanced 1.0.5

- Add Traditional Chinese UI, diagnostics, privacy notice and README, with persistent language selection.
- Standardize Chinese labels for resource packs and shader packs.
- Unify the Linux application ID and visible desktop entry as `minecraft.launcher.advanced`; remove two legacy entries at startup and retarget desktop symlinks pointing to them. Windows application identity and shortcut behavior remain unchanged.
- Fix focus restoration when cancelling skin editing or deletion, and prevent asynchronous saves from taking focus after leaving the page.
- Consolidate application registration and remove duplicate writes, unused parameters and obsolete wording.
- Load launcher release notes only in the selected interface language; switching languages reloads the matching notes without falling back to another language.
